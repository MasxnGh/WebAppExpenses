# บิลบ้าน

เว็บแอปสรุปค่าใช้จ่ายในบ้านรายเดือน ใช้ส่วนตัว ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูล ไม่มี API

## ใช้ยังไง

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร ทำงานออฟไลน์ 100%

## มีอะไรบ้าง

- **บิลรายเดือน** — บันทึกค่าไฟ ค่าน้ำ ค่าเน็ต ค่ามือถือ ฯลฯ รวมยอดอัตโนมัติ
  เทียบกับเดือนก่อน ตั้งงบประมาณ ตั้งบิลประจำแล้วดึงเข้าเดือนใหม่ได้ในคลิกเดียว
- **คืนเงิน** — ยืมเงินจากบัญชีตัวเองมาใช้แล้วทยอยคืน มียอดค้างสะสมแบบสมุดบัญชีธนาคาร
  และคำนวณให้ว่าถ้าคืนเดือนละเท่านี้ อีกกี่เดือนจะหมด
- ธีมมืด/สว่าง สลับได้ ปฏิทินและตัวเลือกเดือนเป็นภาษาไทย พ.ศ.
- สำรอง/กู้คืนข้อมูลเป็นไฟล์ JSON และส่งออก CSV

## ข้อมูลเก็บที่ไหน

`localStorage` ของเบราว์เซอร์ ไม่มีการส่งข้อมูลออกไปไหนทั้งสิ้น
แต่ละเครื่องจึงเก็บข้อมูลของตัวเอง ถ้าจะย้ายให้ใช้ปุ่มสำรอง/กู้คืน

**แนะนำให้กดสำรองข้อมูลเก็บไฟล์ไว้เป็นระยะ** เพราะถ้าล้างข้อมูลเว็บไซต์ในเบราว์เซอร์ ข้อมูลจะหาย

## เอาขึ้นเว็บ

เป็นเว็บนิ่งล้วน อัปทั้งโฟลเดอร์ขึ้นโฮสต์ไหนก็ได้ ไม่ต้อง build ไม่ต้องตั้งค่า

โครงสร้างไฟล์
```
index.html            ตัวแอปทั้งหมด (HTML + CSS + JS ในไฟล์เดียว)
manifest.json         ทำให้ติดตั้งลงหน้าจอโฮมได้เหมือนแอป
icon-192.png          ไอคอนแอป
icon-512.png          ไอคอนแอปความละเอียดสูง
icon-maskable.png     ไอคอนสำหรับ Android ที่ครอบรูปทรงเอง
apple-touch-icon.png  ไอคอนสำหรับ iPhone / iPad
```
